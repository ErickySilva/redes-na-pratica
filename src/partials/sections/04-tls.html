A sua conexão não é particular

O certificado apresentado não corresponde a este endereço, está vencido ou foi emitido por quem o navegador não conhece. O túnel até pode ser montado, mas ninguém garante quem está do outro lado.

CONFIDENCIALIDADE

Ninguém no caminho lê o conteúdo.

INTEGRIDADE

Se um bit for alterado no meio do caminho, a outra ponta detecta e descarta.

AUTENTICIDADE

O certificado prova que o servidor é quem diz ser. O aviso de conexão não particular é essa checagem falhando.

A ordem importa: o TCP conecta, o TLS negocia e confere o certificado, e só então o HTTP começa a falar lá dentro. HTTPS não é outro protocolo, é o mesmo HTTP dentro do túnel.
